# MAFI 2026 – IQF Photos

Companion to the **MAFI 2026** plugin. It contains the 12 IQF (Frozen Fruits & Vegetables) top-view product photos in full 4K resolution, transparent PNG, unchanged. They're kept in a separate plugin because Claude allows at most 200 MB per plugin.

## Components
| Component | Count | Purpose |
|---|---|---|
| Skills | 1 | `mafi-2026-iqf-photos`: provides the IQF top-view photos to the MAFI 2026 brand skill |

## Install
Install **MAFI 2026** first. Then, in Claude on the web or in the desktop app, go to **Customize > Plugins > Add > Upload plugin** and choose `mafi-2026-iqf-photos.plugin`.
